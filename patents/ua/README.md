# Ukrainian patents

Inventions and utility models registered in Ukraine by Alexander Vityaz (Витязь О. П.), most of
them with PrivatBank as co-applicant. They predate the US filings in [`patents/`](../) by roughly
a decade and cover the technologies described in the early interviews: SMS-based one-time
passwords, card personalization, remote authentication, QR payments, and fuel payment by phone.

This is an index, not an archive. Unlike the US grants — whose official publications are public
records downloadable from Google Patents — the Ukrainian register
([sis.ukrpatent.org](https://sis.ukrpatent.org/uk/search/simple/)) serves its documents through a
JavaScript application with no direct link to a PDF, so no `patent.pdf` is stored here. Each row
links to the register entry, which is the authoritative record.

Titles are given in Ukrainian as registered, with an English gloss.
